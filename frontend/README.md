# Frontend PhiveAlpha

Angular dengan locale Indonesia dan lima halaman IDX. Paper Trading menampilkan estimasi bruto dari harga fixture.

```bash
npm ci
npm test
npm run build
npm start
```

Dev server di `http://127.0.0.1:4282` memakai proxy IDX dan memerlukan backend lokal pada port 8182. Build produksi lokal tersedia di `dist/phivealpha/browser`.
